# Sonlet 公开发布准备

基线为 PR #20 的 `6ce2bf9`。GitHub 已公开 `v0.1.0`（versionCode 100），下一候选版本为 `v0.1.1`（101）。现行准入决定仅覆盖内部验证与受限内测。

| 任务 | 验收标准 | 验证 |
|---|---|---|
| 录音与错误恢复 | 按住模式授权后等待新手势。模型不可用时始终拒绝采集。可重试错误支持直接再次录音。录音启动失败会释放资源。 | 状态机回归、权限路径及真机采集测试 |
| 转写完整性 | 格式化保留数字和含数字的标识符。用户可在会话内查看最近一次经过格式化的原文。 | 格式化和交付回归、双语 UI |
| CI 和候选构建 | CI 执行单测和双变体 Lint。签名构建检查版本、签名、模型指纹、ABI、16 KB 对齐及联网权限。公开仓库的工作流只验证候选包。 | JVM、Lint、构建和实际 APK 检验 |
| 发布复核 | 同一签名 APK 记录 SHA-256，并完成覆盖安装、离线冷启动、异常恢复、设备矩阵、3～10 秒的生产路径长稳及准确率验证，或为可豁免项记录负责人决定。 | 候选包验收记录 |
| 分发批准 | 审查人确认权重和 Native 组件分发条件、NOTICE、SBOM 及候选包验收证据。负责人确认后操作公开发布。 | 发布决策和产物记录 |

依次完成应用修复、自动化校验和候选验收。FR-105 自定义词汇仍是独立的 P1 产品待办，公开发布时由负责人确认交付范围。P2 沿用既有决策。

本地装有 Debug 签名时，保留设备现有数据。签名升级实测使用已装上一正式版的测试设备。测试失败时修复后重新构建并核验新产物的哈希。

## 候选包验收记录

- 本地通过 98 项 JVM 单测、4 项 Python 校验测试、Debug 和 Release Lint，以及两个 GitHub Actions 文件的 actionlint 校验。
- 本地候选包为 `Sonlet-0.1.1-arm64-v8a.apk`，versionCode 101，SHA-256 为 `1e46d3a1aeda6d092585cb9f09e0b52dfce6aa947ec19e72a31848730bf66cd8`。证书与 `v0.1.0` 的公开构建记录一致。模型、词表、VAD、许可文件、16 KB ZIP 和 ELF 对齐及离线权限校验通过。
- Android 15 arm64 隔离模拟器在飞行模式下完成同证书 `v0.1.0` tag 重建包到候选包的覆盖安装。候选包首次打开后模型初始化成功。按住、松手后授予麦克风权限，保持等待新手势。模拟器注入固定音频时因宿主音频设备不可用退出，签名包转写回填仍需实测。
- 设备仪器测试分两处运行。Android 14 真机采集测试 7 项和 100 轮长稳通过。Android 15 模拟器运行其余 27 项，其中 26 项通过，准确率评测因缺标注语料跳过。
- 真机长稳每轮采集 3～10 秒。正常结束后以固定中文 PCM 验证生产 VAD、引擎及交付，80 次正常结束各交付一次，20 次取消零交付。Native 堆从第 20 轮的 365,121 KiB 到第 100 轮的 365,572 KiB，固定样本引擎 RTF 的 P50 为 0.040、P95 为 0.041。端到端编辑器延迟和语料准确率仍待测。
- 本地生成了运行时依赖清单，包含 96 个解析后的 Maven 组件和 APK 中的 6 个模型、词表及原生库文件。最终 SBOM 仍需核对 Native 内嵌依赖及其许可证。
- 公开准入待办包括分发签字、NOTICE/SBOM 复核、三档目标真机证据和签名包语音回填，以及 CER/WER、端到端 P95 和 PRD 未达标项的负责人决定。

公开操作前先确认远端默认分支包含本轮工作流修复，并核对正式 tag 将指向已验收的提交。验收记录须绑定即将分发的实际文件 SHA-256。
