# Sonlet 真人验收指南(T4-05 Conditional Go:受限内测)

> 适用版本:0.1.0(debug,2026-11-04 构建)。
> 依据:PRD §15 AC-P0 用例、DESIGN.md 交互规范、T4-05 决策(限内部验证与受限内测,不对外分发)。
> 验收设备:Xiaomi 23078PND5G(Android 14)/ OnePlus PJZ110(Android 17)。
> 记录方式:每项通过打 ✓,失败记 F + 现象描述 + 截图;结果汇总到本文末尾表格。

## 0. 验收前准备(每台设备)

1. 安装 App(已完成):桌面应有 Sonlet 图标(深绿底、杏色 Split S)。
2. 环境:保持**联网状态**做首验(用于证明"有网也不走云端"更好,见 3.2);另留 10 分钟做**飞行模式**专项(3.6)。
3. 麦克风:确认设备麦克风正常(可用系统录音机预录一句)。
4. 不要预先手动授予麦克风权限——权限流程本身是验收项(3.1)。

## 3. 语音主流程

### 3.1 首次权限(AC-P0-003 / 004)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 3.1a | 点"开始语音输入" | 弹系统麦克风权限框;**拒绝**后不闪退,可继续手动编辑,出现就近说明面(可"返回编辑"收起),不会循环弹窗 |
| 3.1b | 再次点开始 | 重新请求;若系统不再弹(永久拒绝),说明面提供"打开设置" |
| 3.1c | 授权(使用中允许) | **授权后自动开始录音**(无需再点一次),状态进入"正在聆听…" |

### 3.2 正常听写与插入(AC-P0-002 / 005 / 011 / 012)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 3.2a | 光标置于空编辑框,说 3~8 秒中文,点"结束并转写" | 状态走 聆听→正在本地转写→可以开始;文字插入**当前光标处**;录音中显示计时与音量波形条 |

| 3.2d | 选中一段文字再听写 | 选区被替换,光标落在替换文本之后 |
| 3.2e | 重复同一 resultId 不可人工构造 | 由自动化测试覆盖(AC-P0-018),本项免 |

### 3.3 边界与取消(AC-P0-006 / 007 / 008 / 013)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 3.3a | 点开始后**立即**(<0.3s)点结束 | 轻提示"录音太短,请再试一次",不弹错误框,正文不变 |
| 3.3b | 静音环境录 30 秒不动 | 到 30s 自动结束并转写;若无可识别语音 → 轻提示"未检测到可识别语音",**正文保持原样** |

| 3.3d | 转写中点"取消" | 回到就绪;本次结果绝不插入 |

## 4. P1 交互(T3-01~04)

| 步骤 | 操作 | 预期 |
|---|---|---|
| 4.1 | 就绪态点底部"按住模式" | 主按钮变"按住说话" |
| 4.2 | **按住**按钮说话 2~5 秒后**松开** | 按下即开始聆听;松开即转写并插入;无多余等待 |
| 4.3 | 按住后**向上滑动**再松手 | 取消本次,无插入 |
| 4.4 | 切回"点击模式" | 恢复点击开始/结束行为 |
| 4.5 | 就绪态选风格:原文/自然/精简/笔记,各录一句含口头重复与填充词(如"嗯 这个 这个 方案") | 原文=逐字;自然=重复折叠;精简=再去除"嗯/呃"等填充词;笔记=按句分行;**四种均不改写语义** |
| 4.6 | 录音中观察波形 | 波形随说话起伏(真实采样),静音时低位;不逐帧闪烁 |
