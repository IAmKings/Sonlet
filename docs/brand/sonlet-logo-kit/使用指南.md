# Sonlet 标识使用指南

Speak locally. Build freely. · 2026-11-04

两段相向的语音回转构成一个 S，呼应 Sonlet 的名称与可组合工具属性。保留 45° 切口与圆弧，不拼接或单独移动两段。

## 选择文件

- 默认：`digital/sonlet-horizontal-color.svg`，用于白色或暖白背景。
- 深色背景：`*-dark.svg`（浅杏色符号＋暖白文字）；纯白反显用 `*-white.svg`。
- 紧凑场景：`sonlet-symbol-color.svg`；16–24 px 使用 `source/sonlet-symbol-small.svg` 或 `web/favicon.svg`。
- 另有 `stacked` 竖排、`wordmark` 纯字标、`tagline` 带口号，以及黑色、品牌单色版本。
- SVG 是矢量主文件；PNG 方便直接使用。所有标识和口号均为自绘填充路径，无字体依赖。

## 安全留白与尺寸

标识周围至少留出一个笔画宽度：符号 256 单位画布上的 32 单位。按比例缩放；应用图标使用已给定的容器比例。

| 形式 | 屏幕最小尺寸 | 常规印刷建议下限 |
|---|---|---|
| 符号 | 16 px（小尺寸专版）；常规版 32 px | 8 mm |
| 横排 | 160 px 宽 | 30 mm 宽 |
| 竖排 / 字标 | 160 / 96 px 宽 | 25 / 20 mm 宽 |
| 带口号 | 500 px 宽 | 65 mm 宽 |

印刷下限为设计建议，需按纸张、工艺和实样确认。

## 配色

| 名称 | HEX | RGB | CMYK 近似 % |
|---|---|---|---|
| Terracotta | #BC482F | 188 / 72 / 47 | 0 / 62 / 75 / 26 |
| Ink | #202B28 | 32 / 43 / 40 | 26 / 0 / 7 / 83 |
| Paper | #F7F5EF | 247 / 245 / 239 | 0 / 1 / 3 / 3 |
| Apricot | #F59C7E | 245 / 156 / 126 | 0 / 36 / 49 / 4 |

陶土橙用于浅底符号，深墨绿用于文字与图标底色；浅杏色用于深底符号。陶土橙对白色约 5.1:1、对暖白约 4.7:1；暖白对深墨绿约 13.4:1。普通正文优先用深墨绿／暖白。CMYK 为不含 ICC 配置的近似换算；未指定 Pantone，印刷前以实样匹配。

## 字体与背景

Sonlet 字标和口号均手工构造轮廓，请勿直接打字重建。日常界面沿用 Android／系统默认无衬线字体；演示页使用系统字体，不附带字体文件。纯黑版用于单色印刷；白色反显版的符号笔画由 32 调整为 30 单位。复杂图片上放置时使用纯色承托。

## 保持一致

等比缩放；保留间距与组合。不要拉伸、旋转、加阴影、加渐变、描边或重排两段 S。小图标不加口号。展示图中的 README、终端和网页仅说明应用效果，不表示产品功能或页面已实现。

商标数据库及反向搜图未核验；公开发布前建议做专业检索。SVG 为 RGB 文件，印刷方需另做色彩管理与实样确认。
