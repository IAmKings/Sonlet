标识使用指南 · 2026-11-04

两段语音回转，一个模块化的 S。

默认使用陶土橙符号与深墨绿字标。保留圆弧、45° 切口和两段之间的开口。

Terracotta#BC482F
Ink#202B28
Paper#F7F5EF
Apricot#F59C7E

01 / 选择版本

浅底：horizontal-color。
深底：horizontal-dark；纯白使用 white。
紧凑位置：symbol；小图使用 small。
另有竖排 stacked、纯字标 wordmark、带口号 tagline。

02 / 留白与最小尺寸

四周至少留一个笔画宽度（256 网格中的 32 单位）。整体等比缩放。

版本屏幕下限
小尺寸 / 常规符号16 / 32 px
横排 / 竖排160 px 宽
纯字标 / 带口号96 / 500 px 宽

03 / 文件与字体

SVG 是主文件，PNG 可直接使用。字标与口号均为手工构造的填充路径，不需要安装字体。界面文字使用系统默认无衬线字体。

04 / 背景与可读性

白色或暖白背景用陶土橙＋深墨绿。深墨绿背景用浅杏＋暖白。复杂图片上加纯色承托。

陶土橙对白色约 5.1:1、对暖白约 4.7:1。普通正文优先深墨绿／暖白。反显符号笔画由 32 减为 30 单位。

05 / 保持一致

不要拉伸、旋转、描边、加阴影或渐变；不要移动两段 S、改变组合间距或打字重建字标。小图标不加口号。

06 / Web 与 Android

Web 图标、manifest 与引用片段见 web/。Android 提供前景、背景和 monochrome 资源；由启动器裁切形状。集成说明见 README.md。

07 / 印刷

RGB 为数字主色。近似 CMYK 见 palette.json，未指定 Pantone；印刷需确认纸张、色彩管理和实样。符号建议 ≥8 mm，横排 ≥30 mm。
