# 研发日志 · 2026-11

## 2026-11-19 · feat-11-19-ui-polish · 主界面视觉与状态表达优化

**业务价值**：首发版本（v0.1.0）的界面与 `DESIGN.md` 设计基线脱节——控制面被 M3 的 surfaceTint 染成淡粉、模式切换用「禁用」表达「未选中」导致语义反向、按住模式主按钮在白面板上不可见。本次把主界面拉回基线，并顺手修掉两处只有真机才会暴露的布局缺陷。

**关键改动**（3 个提交，PR #19 / #20）：
- `70b30ae` 页面底色走 `MaterialTheme.colorScheme.background`，修深色模式整页露白。
- `4319661` 控制面去 `tonalElevation`、改 1dp `outlineVariant` 边界；模式切换改 `SingleChoiceSegmentedButtonRow` 并修正选中语义；READY 状态行降为 `bodyMedium` + `onSurfaceVariant`。
- `321c770` 按住按钮补容器与前景色；风格选择补分组标签；静音波形改用 `onSurfaceVariant` 0.35 alpha。
- `6ce2bf9`（PR #20）整页可滚动 + 系统栏内边距，修 200% 字体与横屏截断。

**验证**：96 例单测全绿；仪器测试 34 例首次整套跑通（9 个类，含手势、转屏、权限）；真机截图覆盖浅色/深色 × 点击/按住 × 默认字号/200% 字体/横屏。

**沉淀**：
- Compose 手势测试用 `UiAutomation.injectInputEvent` 注入真实 DOWN/UP，`performTouchInput` 跨 block 会丢抬手事件。
- 转屏验收用 `settings put system user_rotation 1`（`cmd window user-rotation lock` 无效）。
- 滚动容器内的子项不能用 `weight(1f)`，需按可用高度计算。

## 2026-11-20 · feat-11-20-segment-dark-tone · 深色模式分段控件选中态降权

**业务价值**：深色下模式切换的选中段是整块 `primaryContainer`(#6E2E1B) 深红实心块，紧贴主按钮上方，两块暖色抢主次，违背 DESIGN.md §1「录音状态必须比品牌装饰更明确」。降权后主按钮重新成为全屏唯一的暖色实心块。

**改动**（PR #26 → `cb5d491`，仅 `DictationScreen.kt` 的 `ModeToggleRow`）：深色下 `activeContainerColor` 改 `primary.copy(alpha = 0.18f)`、`activeContentColor` 改 `onSurface`、描边 `primary.copy(alpha = 0.55f)`；浅色保持 `primaryContainer` 不变。

**验证**：深色实测填充 #38322D / 文字 #C6C4BF，对比度 7.25:1；浅色选中段仍为 #FFDBD1 + #3D0A00，外观无变化；单测 96 例全绿；PR CI 双绿。

**沉淀**：`Theme.kt` 只定义了 `surfaceVariant`，没有 `surfaceContainerHighest`——用它会让 M3 落回基线紫灰(#2B2A2F)，与暖色调冲突。需要"比 surface 略亮"的中性面时，用 `primary.copy(alpha)` 叠加比引用未定义角色安全。

## 2026-11-20 · refactor-11-20-journal-in-git · 研发日志纳入版本管理

**业务价值**：此前 `/.trellis/` 整目录被忽略，研发日志只存在于本机——换机器、clone、或别人接手都看不到"为什么这么改"。现在日志随仓库流转。

**改动**（PR #27 → `2b02c1f`）：`.gitignore` 里 `/.trellis/` 改为 `/.trellis/*` + `!/.trellis/journal/`。前者只匹配直接子项、不排除目录本身，因此 git 会继续下钻；后者重新包含 journal。任务目录、`.runtime/` 继续被忽略。

**验证**：`git check-ignore -v` 确认 journal 不再命中、`task.json` 与 `current_task` 仍命中；合并后 `git ls-files .trellis` 只有 `journal/2026-11.md` 一个文件。

**沉淀**：gitignore 里父目录用 `dir/` 形式排除后，目录内的 `!` 反向例外无效（git 不会进入该目录）。要"只放开子目录"，必须写成 `dir/*` + `!dir/子目录/`。
